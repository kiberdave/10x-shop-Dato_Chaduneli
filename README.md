# 10X Shop

Online store SPA — React 19, TypeScript (strict), Tailwind CSS v4 and the DummyJSON products API.
10X Academy front-end graduation project. Work in progress.

## How to run

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — dev server
- `npm run build` — type-check and production build
- `npm run typecheck` — TypeScript check without emitting files
- `npm run lint` — ESLint
- `npm run preview` — serve the production build
